# codesIR

A personal project to get my old aircon working with [SmartIR](https://github.com/smartHomeHub/SmartIR). It converts the input JSON file into a command format that SmartIR expects. My aircon model is a panasonic CS-S18KKT.

## Usage

run `python [input].json [output].json` to get a output JSON file that has a command key which can be used to create SmartIR codes/climate file. 


## Contents
- `script.py` contains the script to convert the input file
- `input.json` the raw input JSON file which was created using Home Assitant's remote.learn_command with a Broadlink RM4
- `output.json` the output file generated by the script
- `panasonic_CS-S18KKT.json` the complete smartIR file made by hand using the template and output file
